# strong-bonds.org

Public website for Strong Bonds Resilience, Inc. — the nonprofit arm of the Strong Bonds Family of Companies. Serves Fort Bliss soldiers, veterans, and UTEP/EPCC students with peer support, transitional housing (Sarah's Place), and housing for unhoused veterans (The Veteran Village).
